# XOR gate
## Made from NPN transistors
### Breadboard version

**Important:**

- A naive approach would be to use 8 gates to construct the XOR gate, but
thanks to Ben Eater, we can use 5 gates and get the same functionality!

- Here I learned more about how should I place transistors. It took so much
to construct this gate in real life, but hopefully it will get better from now
on.
